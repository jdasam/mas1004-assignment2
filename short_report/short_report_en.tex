\section*{What LaTeX is}

This file is written in LaTeX. A LaTeX file is plain text with a few commands
in it, and every command starts with a backslash, such as \verb|\section*|. On
Overleaf the file is on the left and the PDF on the right. When you press
Recompile, Overleaf reads the file and makes the PDF again.

Everything on this page comes from the file on the left. Compare the left and
the right to see how each part is written. Then delete this guide, from
\verb|\section*{What LaTeX is}| down to the line before \verb|\figurepages|,
and write your report in its place.

\section*{Writing text}

\begin{itemize}
  \item Type your sentences as they are. Line breaks inside a paragraph make no
    difference: LaTeX breaks the lines itself.
  \item A blank line starts a new paragraph.
  \item \verb|\section*{A heading}| makes a heading like the ones on this page.
    You do not have to use headings.
  \item A list like this one starts with \verb|\begin{itemize}|, has
    \verb|\item| before each point, and ends with \verb|\end{itemize}|.
\end{itemize}

\section*{Special characters}

A \verb|%| starts a comment: the rest of that line does not appear in the PDF.
The lines at the top of the file are comments. To print one of
\verb|% $ & # _ { }|, put a backslash in front of it: \verb|\%|, \verb|\$|,
\verb|\&|, \verb|\#|, \verb|\_|, \verb|\{|, \verb|\}|.

\section*{When something goes wrong}

\begin{itemize}
  \item If Recompile shows an error, look at the line number in the message.
    Most often a \verb|}| is missing, or one of the special characters above
    has no backslash in front of it.
  \item If the text runs past one page, a red note appears at the end of it.
    The same happens if the figures take more than three pages.
\end{itemize}
